# neweramovement.org

Landing page for The New Era Movement, with its initiatives Pasai and Conscious Pulse.

Static site on GitHub Pages; custom domain in `CNAME` (neweramovement.com forwards here from Domeneshop).
Everything lives in `index.html`: the original emblem (`emblem.webp`) with live light animated over it as SVG,
a canvas starfield background, the wordmark as live type, the Pasai mark as inline SVG and the Conscious Pulse
icon (`cp-icon.webp`). Fonts are self-hosted in `fonts/`.
