# neweramovement.org

Landing page for The New Era Movement, with its initiatives Conscious Pulse and Pasai.

Static site served by GitHub Pages; custom domain in `CNAME`. Everything lives in `index.html`:
the emblem, the Conscious Pulse and Pasai marks are inline SVG, animated live. Fonts are self-hosted in `fonts/`.
`emblem.webp` is used only as the social share image.
