# neweramovement.org

Landing page for The New Era Movement and its initiatives, Pasai and Conscious Pulse.

Static site on GitHub Pages; custom domain in `CNAME` (neweramovement.com forwards here from Domeneshop).
Everything lives in `index.html`: the original emblem (`emblem.webp`) with live light animated over it as SVG,
a canvas starfield, the wordmark as live type, and the Pasai and Conscious Pulse orbs as inline SVG
("Luminous Ascent" design: gold ring, glass interior, one symbol drawn in light). Fonts are self-hosted in `fonts/`.
